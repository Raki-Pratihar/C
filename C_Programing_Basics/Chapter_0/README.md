### History of C language 
The **C programming language** was developed by **Dennis Ritchie** at Bell Laboratories in 1972. It was designed as a general-purpose programming language and became widely used for system programming and operating system development.


* **1967 — BCPL:** Developed by Martin Richards.
* **1970 — B Language:** Developed by Ken Thompson.
* **1972 — C Language:** Developed by Dennis Ritchie at Bell Laboratories.
* **1978 — The C Programming Language:** Brian Kernighan and Dennis Ritchie published a famous book on C, commonly known as *K&R C*.
* **1989 — ANSI C (C89):** C was standardized by the American National Standards Institute (ANSI).

### Importance of C

* Used in operating systems and system programming.
* Widely used in embedded systems.
* Provides a foundation for learning programming concepts.
* Gsmes are buile on C.
* Influenced many modern programming languages, including C++, Java, and C#.

### Programing
**Programming** is the process of writing instructions that tell a computer how to perform specific tasks. These instructions are written using programming languages such as C, C++, Python, and JavaScript.

Programming helps us solve problems, automate tasks, develop software, and build websites and applications.

#### Why Learn Programming?

* **Problem-Solving:** Develop logical and analytical thinking.
* **Automation:** Automate repetitive tasks.
* **Software Development:** Build applications, websites, and operating systems.
* **Innovation:** Turn ideas into practical solutions.

### gcc compiler
GCC (GNU Compiler Collection) is a free, open-source compiler that converts programming code written in languages like C, C++, and Fortran into machine code that a computer can execute.

#### Key points:
* Full form: GNU Compiler Collection.
* Purpose: Converts source code into executable programs.
* Languages supported: C, C++, Fortran, and others.
* Operating systems: Windows, Linux, and macOS.
* Common use: Compiling and running C/C++ programs.
* Example: GCC uses the gcc command to compile C programs.
